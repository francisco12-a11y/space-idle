# Stellar Ascent

A space-themed incremental/idle game. Start on Terra Nova, mine Metal, build colonies,
research techs, and expand to Luna, the Ceres Belt, and the ringed giant Aurelia.

**Play:** https://francisco12-a11y.github.io/space-idle/

## Features
- 4 planets, each with a unique resource, 3 buildings and 3 upgrades
- Click mining (power scales with production) + idle generators
- Science from Research Labs feeding an 11-node tech tree
- Offline progress (50%, or 75% with a tech)
- Autosave every 10s to localStorage

## Dev
Pure static HTML/CSS/JS — no build step. Deploys to GitHub Pages via Actions on push to `main`.
